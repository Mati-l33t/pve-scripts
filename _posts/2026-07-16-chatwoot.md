## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVED/main/ct/chatwoot.sh)"
```

Config file:
```
/opt/chatwoot/.env
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Create the first account at http://IP:3000 after the services have started.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Set FRONTEND_URL to a public HTTPS domain and configure SMTP before using Chatwoot in production.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Attachments are stored in /opt/chatwoot/storage. Include it and the PostgreSQL database in regular container backups.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Chatwoot compiles Ruby dependencies and frontend assets during installation; allow several minutes for setup.</div>
</div>
