```bash

```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The gRPC endpoint on port 7233 and the UI on 8080 have no authentication. Keep the container on a trusted network or put it behind a firewall and a TLS proxy.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Point workers and SDK clients at [IP]:7233. The temporal CLI is installed in the container and already talks to the local server; the default namespace is created with a 72h retention.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The database password lives in /etc/temporal/temporal.env; the server config in /etc/temporal/config/production.yaml reads it from there. Restart temporal after changing either file.</div>
</div>
