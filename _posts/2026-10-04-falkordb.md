## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/falkordb.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Log in to FalkorDB Browser with host localhost, port 6379, an empty username and the requirepass password from /etc/redis/falkordb.conf.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>If you open the browser under another address (new IP, hostname, reverse proxy), set NEXTAUTH_URL in /opt/falkordb-browser_data/.env and run systemctl restart falkordb-browser.</div>
</div>
