## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVED/main/ct/falkordb.sh)"
```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The Redis password is generated at install and stored as requirepass in /etc/redis/falkordb.conf. FalkorDB itself listens on port 6379.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Try it from the container: redis-cli -a <password> GRAPH.QUERY social "CREATE (:Person {name:'Alice'})-[:KNOWS]->(:Person {name:'Bob'})", then redis-cli -a <password> GRAPH.QUERY social "MATCH (a)-[:KNOWS]->(b) RETURN a.name, b.name".</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>FalkorDB Browser runs on port 3000. Log in with host localhost, port 6379, an empty username and the requirepass password. If you reach it under another address (new IP, hostname, reverse proxy), set NEXTAUTH_URL in /opt/falkordb-browser_data/.env and restart falkordb-browser.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>FalkorDB is loaded as a module into Redis 8 from packages.redis.io (service redis-server). Module arguments sit on the loadmodule line in /etc/redis/falkordb.conf; graph data (RDB and AOF) lives in /var/lib/redis, and LOAD CSV reads from /var/lib/FalkorDB/import.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The 4 GB RAM are for building FalkorDB Browser during install and browser updates (peak about 3.4 GB). At runtime FalkorDB and the browser use about 200 MB plus your graph data.</div>
</div>
