
## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Sign in at http://[IP]:8888 with ADMIN_EMAIL and ADMIN_PASSWORD from /opt/hatchet_data/.env. Sign-up is off; set SERVER_ALLOW_SIGNUP=t there to allow it.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Workers need an API token from the dashboard and HATCHET_CLIENT_TLS_STRATEGY=none, because gRPC on port 7077 runs without TLS.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Tokens and logins are bound to the container IP in the .env. Use a static IP, or after a change update SERVER_URL, SERVER_GRPC_BROADCAST_ADDRESS and SERVER_AUTH_COOKIE_DOMAIN and create new tokens.</div>
</div>
