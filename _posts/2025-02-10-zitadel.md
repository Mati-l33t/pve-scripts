## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/zitadel.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Sign in at /ui/console as zitadel-admin@zitadel.localhost with the initial password from ~/zitadel.creds in the container. Zitadel asks for a new password at the first sign-in.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>With Login V2 (default) Zitadel runs at https://[IP]:8080 with a self-signed certificate; accept it in the browser. Login V1 stays on plain http://[IP]:8080.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Zitadel only answers on the ExternalDomain in /opt/zitadel/config.yaml (the container IP). To use a hostname, change it, run zitadel setup --masterkeyFile /opt/zitadel/.masterkey --config /opt/zitadel/config.yaml and restart zitadel.</div>
</div>
