```bash

```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Rallly signs users in with codes sent by email: fill in the SMTP fields when creating the container, or set SMTP_* in /opt/rallly_data/.env and run systemctl restart rallly.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Without SMTP, request a code on the login page and read it in the container: su postgres -c "psql rallly -tAc 'select value from verifications'" (the digits before the colon).</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Sign in with the admin email and open /control-panel to claim the admin role. Until registration is turned off there, anyone who reaches the page can create an account.</div>
</div>
