## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVED/main/ct/ignis.sh)"
```

Config file:
```
/etc/systemd/system/ignis.service
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Open https://[IP] and accept the self-signed certificate. HTTPS is required: outside a secure browser context Obsidian's browser APIs (OPFS, service workers) are disabled and the app will not load correctly. nginx terminates TLS and proxies to the Node server on port 8080.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Ignis has NO built-in authentication. Do not expose it directly to the internet - put an authenticating reverse proxy (or VPN) in front of it before allowing remote access.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Vaults and application data live in /opt/ignis_data (vaults, data, obsidian-app), kept outside the app directory so they survive updates. Include /opt/ignis_data in regular backups.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>On install the matching Obsidian web build is downloaded and unpacked automatically. A default vault is created on first start (AUTO_CREATE_DEFAULT).</div>
</div>
