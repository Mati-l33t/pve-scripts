## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/t3code.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Log in to the provider CLIs (Codex, Claude, Grok, OpenCode, GitHub) inside the container before using them in T3 Code.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Agents run as root with Claude's Full access mode allowed, so they can change anything in the container and in writable bind mounts. Keep the container unprivileged and do not mount sensitive host paths.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The pairing URL shown after the install expires after an hour. Get a new one with pct exec [CTID] -- t3 pair --base-dir /opt/t3code.</div>
</div>
