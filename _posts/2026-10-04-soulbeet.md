## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Soulbeet ships a local admin / admin account. Change its password in Settings > Users right after the first login. Once NAVIDROME_URL is set, users log in with their Navidrome credentials instead.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Soulbeet's sign-up API accepts requests without a login, and any logged-in user can change any other user's password. Anyone who reaches port 9765 can therefore take over the instance, including the slskd API key stored in it. Keep it on a trusted network and do not expose it to the internet.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Soulbeet needs an slskd 0.26 or newer instance, which is not part of this container (use the slskd script for one). Enter its URL and API key in Settings > Config.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Soulbeet imports what slskd downloads straight from disk, so slskd's downloads directory has to be mounted into this container at /opt/soulbeet_data/downloads, e.g. pct set [CTID] -mp0 /path/to/slskd/downloads,mp=/opt/soulbeet_data/downloads.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Add library folders in Settings > Library. /opt/soulbeet_data/music is prepared for that; mount the music share Navidrome reads at that path so imported tracks show up there.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Discovery playlists, rating sync and Navidrome logins need NAVIDROME_URL in /opt/soulbeet_data/.env. Uncomment it, then run systemctl restart soulbeet.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>beets is installed with the plugin set of upstream's default (light) image: MusicBrainz tagging. Its configuration is /opt/soulbeet_data/beets_config.yaml, and pure-Python plugins can be dropped into /opt/soulbeet_data/beets-plugins.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Install and every update compile Soulbeet from source (Rust server plus WebAssembly client), which takes about 6 to 9 minutes on 4 cores. The running app needs well under 512 MB, so the RAM can be lowered after the install and raised again before an update.</div>
</div>
