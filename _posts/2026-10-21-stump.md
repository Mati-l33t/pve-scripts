## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/stump.sh)"
```
<div class="resource-bar">
  <span class="res-pill res-cpu">CPU: 2 cores</span>
  <span class="res-pill res-ram">RAM: 1024 MB</span>
  <span class="res-pill res-disk">Disk: 8 GB</span>
  <span class="res-pill res-os">OS: Debian 13</span>
</div>

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>There is no default login: the first account created in the onboarding becomes the owner. Anyone who reaches the port can claim the server until then, so do it right after the install.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Create a library pointing at /opt/stump_data/library. To use a host folder, mount it there with pct set [CTID] -mp0 /path/on/host,mp=/opt/stump_data/library.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>OPDS readers connect to http://[IP]:10801/opds/v1.2/catalog (or /opds/v2.0/catalog) with a Stump username and password.</div>
</div>
