## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The web UI and API have no login. Anyone who reaches port 19898 controls the agent, which can run shell commands, so keep it on a trusted network or behind an authenticating reverse proxy.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Without a preset endpoint, add an LLM provider key under Settings in the web UI before the agent can reply.</div>
</div>
