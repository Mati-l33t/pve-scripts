## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>ACLs are off, so the UI on port 4646 is open to anyone who can reach it. Enable ACLs or restrict access before exposing it beyond a trusted network.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Docker is not installed, so the docker task driver is unavailable. The exec, raw_exec and java drivers work out of the box.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>This is a single node acting as server and client. To join more nodes, edit /etc/nomad.d/nomad.hcl and restart the service.</div>
</div>
