## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVED/main/ct/nomad.sh)"
```

  <span class="res-pill res-cpu">CPU: 2 cores</span>

## Configuration

Config file:
```
/etc/nomad.d/nomad.hcl
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>This is a single-node setup: server and client are both enabled with bootstrap_expect = 1. To join more nodes, edit /etc/nomad.d/nomad.hcl and restart the service.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>ACLs are disabled by default, so the UI on port 4646 is open to anyone who can reach it. Enable the ACL system or restrict access before exposing this beyond a trusted network.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The Docker task driver needs a working Docker daemon in the same container, which is not installed here. Out of the box the exec, raw_exec and java drivers are available.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>State lives in /opt/nomad_data. Installed from the official HashiCorp apt repository, so updates go through 'apt install nomad'.</div>
</div>
