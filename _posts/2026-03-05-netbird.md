## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/netbird.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>

</div>
