## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/prefect.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The UI asks for the full user:password auth string from /opt/prefect_data/.env. Clients need it as PREFECT_API_AUTH_STRING, plus PREFECT_API_URL=http://[IP]:4200/api.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Anyone with the auth string can deploy flows that run as root in this container. Install the packages your flows need with uv pip install --python /opt/prefect/.venv/bin/python.</div>
</div>
