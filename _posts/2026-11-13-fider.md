## Installation

**Default install:**
```bash

```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Fider signs users in with emailed links: fill in the SMTP fields when creating the container, or set EMAIL_SMTP_* in /opt/fider_data/.env and run systemctl restart fider.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Without SMTP, submit the setup form, then run su postgres -c "psql fider -tAc 'select key from email_verifications order by id desc limit 1'" and open http://[IP]:3000/signup/verify?k=&lt;key&gt;.</div>
</div>
