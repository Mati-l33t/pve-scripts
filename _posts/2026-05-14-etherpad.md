**Default install:**
```bash

```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The default install uses an embedded sqlite database at /var/lib/etherpad/etherpad.db — ACID, zero-config, suitable for single-instance homelab use. To use postgres or mysql instead, edit /opt/etherpad-lite/settings.json and switch 'dbType' + 'dbSettings' (Etherpad's ueberdb abstraction supports both).</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>View logs with: journalctl -u etherpad -f</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Etherpad listens on port 9001. Restart the service after editing settings.json: systemctl restart etherpad</div>
</div>
