## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>One script serves both variants: the installer asks for the container OS, or pass var_os=alpine to pick Alpine unattended.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The admin password is generated during the installation and saved to /root/openlist.creds inside the container. Change it with <code>/opt/openlist/openlist --data /opt/openlist_data admin set <password></code>.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Config, database, logs and search index live in /opt/openlist_data, outside the directory an update replaces, so updating never touches them.</div>
</div>
