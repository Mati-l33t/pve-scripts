## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/yamtrack.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Set API keys (TMDB_API, MAL_API, IGDB_ID, IGDB_SECRET) in <code>/opt/yamtrack/src/.env</code> to enable media search from external providers.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>If using a reverse proxy, set the <code>URLS</code> variable in <code>.env</code> to your external URL (e.g., <code>URLS=https://yamtrack.example.com</code>).</div>
</div>
