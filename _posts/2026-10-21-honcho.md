## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/honcho.sh)"
```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Honcho needs an API key for OpenAI, Anthropic or Gemini, or an OpenAI-compatible endpoint such as Ollama. Without one the install leaves it stopped.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>There is no web interface. Every API request needs a key sent as Authorization: Bearer &lt;key&gt;; the install prints an admin key.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Port 8000 is plain HTTP, and /docs and /health answer without a key. Put a reverse proxy with TLS in front before exposing Honcho beyond your LAN.</div>
</div>
