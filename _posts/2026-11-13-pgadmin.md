## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/tools/addon/pgadmin.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Run it inside an existing Debian or Ubuntu LXC (amd64 only), typically the one running PostgreSQL. pgAdmin is served at http://[IP]/pgadmin4.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The login email and a generated password are shown once at the end of the install and are not saved anywhere else.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Lost the password: run <code>/usr/pgadmin4/venv/bin/python3 /usr/pgadmin4/web/setup.py update-user &lt;email&gt; --password &lt;new&gt;</code> in the container. Saved server passwords must then be entered again.</div>
</div>
