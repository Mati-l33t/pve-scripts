## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/ytptube.sh)"
```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>There is no default login: the first visitor creates the admin account, so open the web UI right after the install.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>To keep downloads on a NAS or share them with Plex or Jellyfin, mount that folder at /opt/ytptube_data/downloads (pct set [CTID] -mp0 /host/path,mp=/opt/ytptube_data/downloads). The host folder must be writable by UID 100000.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>To reset a password, stop ytptube and run: cd /opt/ytptube &amp;&amp; YTP_CONFIG_PATH=/opt/ytptube_data/config .venv/bin/python -m app.scripts.reset_password --username &lt;name&gt;</div>
</div>
