## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVED/main/ct/plane.sh)"
```

  <span class="res-pill res-cpu">CPU: 4 cores</span>

  <span class="res-pill res-disk">Disk: 8 GB</span>

Config file:
```
/opt/plane/apps/api/.env
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>First user to sign up becomes the instance admin. Initial build takes 10-15 minutes.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Admin panel (God Mode) is available at <code>/god-mode/</code> for instance configuration.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Credentials are saved to <code>~/plane.creds</code>.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>If the container IP changes, rebuild the frontend apps or run the update script to apply the new URL.</div>
</div>
