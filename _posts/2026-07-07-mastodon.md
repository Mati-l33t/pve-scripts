## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/mastodon.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Installation compiles Ruby 4.0.5 and ffmpeg from source — this takes 15–30 minutes.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Admin credentials (email + password) are saved to ~/mastodon.creds.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>This installation uses the container IP and HTTP, so it is suitable only for LAN or testing. LOCAL_DOMAIN must not be changed after initial setup; reinstall with a public domain and TLS before enabling federation.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>SMTP is not configured by default. Set SMTP_SERVER, SMTP_LOGIN, and SMTP_PASSWORD in .env.production for email notifications.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>New account registrations require Owner approval by default.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Media uploads are stored in /opt/mastodon/public/system. Increase disk size if you expect heavy media usage.</div>
</div>
