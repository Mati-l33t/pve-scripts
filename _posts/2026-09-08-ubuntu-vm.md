## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/vm/ubuntu-vm.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Choose the release in Advanced settings, or set VM_OS_VERSION for unattended deployment. End-of-life interim releases 24.10 and 25.04 are no longer offered.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Cloud-Init is offered for credentials, SSH keys and networking. Unattended deployment enables it by default. If explicitly disabled, the script attempts offline root expansion, but guest networking and credentials must be configured manually.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>

</div>
