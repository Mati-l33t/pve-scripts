## Installation

**Default install:**
```bash

```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The script asks which Ubuntu release to install. It replaces the former separate ubuntu2204/2404/2410/2504/2604-vm scripts; 24.10 was dropped because it is end of life and its cloud image has been removed from the mirror.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Cloud-Init is optional and off by default. Without it the disk is only resized on the Proxmox side, so the guest may need its root filesystem expanded manually after first boot.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>If you use Cloud-init, checkout cloud-init discussion: <code>https://github.com/community-scripts/ProxmoxVE/discussions/272</code></div>
</div>
