## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVED/main/ct/docspell.sh)"
```

  <span class="res-pill res-cpu">CPU: 4 cores</span>

## Configuration

Config file:
```
/etc/docspell-restserver/docspell-server.conf
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Create the first account at http://IP:7880. For the initial local signup, use the same value for the collective and username.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Signup is open by default. Configure a reverse proxy with TLS and change the signup mode before exposing Docspell to the internet.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Documents and metadata are stored in PostgreSQL. Back up the Docspell database before upgrades and include it in regular container backups.</div>
</div>
