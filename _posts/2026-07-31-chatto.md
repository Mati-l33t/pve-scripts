## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/chatto.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Register the first account in the web UI, or run cd /opt/chatto &amp;&amp; ./chatto operator user create --login &lt;name&gt;. Logins such as root, admin, op and operator are blocked.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Set SMTP credentials and a public webserver.url in /opt/chatto_data/chatto.toml before using Chatto in production.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Voice and video calls need a separately deployed LiveKit server, configured in the [livekit] section of chatto.toml.</div>
</div>
