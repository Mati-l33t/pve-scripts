## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/coder.sh)"
```

  <span class="res-pill res-cpu">CPU: 2 cores</span>

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The admin login is in /opt/coder_data/.env.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Docker is not available in the container, so the Docker starter templates do not work. Use templates that provision Proxmox VMs, cloud machines or existing SSH hosts.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Workspaces must reach CODER_ACCESS_URL; port forwarding to subdomains needs a real domain with a wildcard (CODER_WILDCARD_ACCESS_URL) in /etc/coder.d/coder.env.</div>
</div>
