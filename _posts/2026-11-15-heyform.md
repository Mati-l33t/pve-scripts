## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/heyform.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Open https://[IP], accept the self-signed certificate and sign up. Sign-up asks for no email code until you set SMTP_* and VERIFY_USER_EMAIL=true in /opt/heyform_data/.env.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Anyone who can reach the URL can create an account: after signing up, set APP_DISABLE_REGISTRATION=true in /opt/heyform_data/.env and run systemctl restart heyform.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>MongoDB 8 needs a CPU with AVX; set the VM/host CPU type to host (not kvm64) on older Proxmox setups.</div>
</div>
