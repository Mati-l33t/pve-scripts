## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/scrutiny.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The container cannot read the disks. Install smartmontools and the scrutiny-collector-metrics binary on the Proxmox host and run <code>scrutiny-collector-metrics run --api-endpoint http://&lt;container-ip&gt;:8080</code> from cron (see the upstream manual install guide).</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The web UI has no login. Keep port 8080 inside your LAN or put it behind a reverse proxy with authentication.</div>
</div>
