## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Log in with admin / admin123 and change the password immediately - the UI prompts for it on first login.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Borg 1 and Borg 2 are both installed, as 'borg' and 'borg2'. Their versions are not chosen by this script: they are read from docker/runtime-base.env in the upstream repository, which is Borg-UI's declared single source of truth, so an update follows whatever the release pins. rclone is installed from the same file for rclone:// repositories and cloud mirroring.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>This container backs up what it can see. Mount the directories you want to protect into the LXC, and for remote repositories deploy an SSH key from the UI to the target host.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>ENABLE_STARTUP_LICENSE_SYNC is set to false in /opt/borg-ui/.env so the container does not contact the upstream licence service on every start. Set it to true if you use a paid licence.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Application data lives in /opt/borg-ui_data. The Borg repositories themselves are wherever you point them - those are the ones that actually matter for backups.</div>
</div>
