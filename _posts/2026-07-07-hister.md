## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/hister.sh)"
```
<div class="resource-bar">
  <span class="res-pill res-cpu">CPU: 1 cores</span>

  <span class="res-pill res-disk">Disk: 20 GB</span>
  <span class="res-pill res-os">OS: Debian 13</span>
</div>

## Configuration

Config file:
```
/etc/hister/config.yaml
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Install the Hister browser extension (Chrome or Firefox) and set the server URL to http://YOUR_IP:4433.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Search index and data are stored in /opt/hister/data. Disk usage grows as more pages are indexed.</div>
</div>
