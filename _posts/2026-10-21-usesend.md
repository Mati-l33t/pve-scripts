## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/usesend.sh)"
```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Sign-in is GitHub OAuth only, and the first sign-in claims the instance. Anyone with a GitHub account who reaches the port can do that, so sign in right after setting up OAuth.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Sending needs Amazon SES: set AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY in /opt/usesend_data/.env, then add SES under Admin with a callback URL reachable from the internet.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Behind a domain or after an IP change, update NEXTAUTH_URL in /opt/usesend_data/.env and the OAuth callback URL, then restart usesend.</div>
</div>
