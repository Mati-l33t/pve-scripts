## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/convex.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Log in to the dashboard with the deployment URL http://[IP]:3210 and CONVEX_SELF_HOSTED_ADMIN_KEY from /opt/convex_data/.env.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>To deploy a project, put CONVEX_SELF_HOSTED_URL=http://[IP]:3210 and the same admin key into its .env.local and run npx convex dev.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Behind a domain or reverse proxy, set CONVEX_CLOUD_ORIGIN and CONVEX_SITE_ORIGIN in /opt/convex_data/.env to the public URLs and restart convex.</div>
</div>
