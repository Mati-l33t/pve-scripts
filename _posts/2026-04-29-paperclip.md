## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The installer attempts Paperclip authenticated/private onboarding for LAN access. If a Paperclip release falls back to local quickstart behavior, first access will not require login and you can switch modes later with <code>pnpm paperclipai configure --section server</code>.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Persistent Paperclip runtime data is stored in <code>/opt/paperclip-data</code>, while the application code lives in <code>/opt/paperclip</code>.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Database credentials are stored in <code>~/paperclip.creds</code>. These are PostgreSQL credentials generated by the shared helper, not the Paperclip web login or Codex/Claude authentication.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>If authenticated mode is active, the installer saves the current CEO bootstrap invite in <code>~/paperclip.creds</code>. Open that invite to finish the initial admin setup. You can generate a fresh invite later with <code>cd /opt/paperclip && set -a && source /opt/paperclip/.env && set +a && pnpm paperclipai auth bootstrap-ceo</code>.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>If you access Paperclip from a different hostname, update <code>PAPERCLIP_PUBLIC_URL</code> in <code>/opt/paperclip/.env</code> and restart the <code>paperclip</code> service. For authenticated/private hostname access, run <code>cd /opt/paperclip && set -a && source /opt/paperclip/.env && set +a && pnpm paperclipai allowed-hostname <hostname></code> after the first startup.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>If you want to change Paperclip's deployment mode later, run <code>cd /opt/paperclip && set -a && source /opt/paperclip/.env && set +a && pnpm paperclipai configure --section server</code>.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Codex and Claude Code are preinstalled. Because the Paperclip service runs as root, authenticate them as root inside the container so Paperclip can reuse those credentials.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>For Codex, run <code>codex</code> and choose ChatGPT login for interactive use, or use API-key authentication for more programmatic workflows. Claude Code can be authenticated by running <code>claude</code> and using <code>/login</code>, or by providing Anthropic API credentials.</div>
</div>
