## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/emdash.sh)"
```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The admin at /_emdash/admin signs in with passkeys only, which browsers allow on HTTPS with a domain or on localhost, never on an IP. The first account cannot be created at http://[IP]:4321.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Behind a reverse proxy with a trusted certificate, set EMDASH_SITE_URL in /opt/emdash_data/.env to its exact address and rebuild: cd /opt/emdash &amp;&amp; set -a &amp;&amp; . /opt/emdash_data/.env &amp;&amp; set +a &amp;&amp; pnpm build &amp;&amp; systemctl restart emdash</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>To try it without a domain, set EMDASH_SITE_URL=http://localhost:4321, rebuild, run ssh -L 4321:localhost:4321 root@[IP] and open http://localhost:4321/_emdash/admin.</div>
</div>
