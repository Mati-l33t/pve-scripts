**Default install:**
```bash

```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Without an API key the API accepts requests from anyone. Set VLLM_API_KEY in /opt/vllm/vllm.env (clients send it as a bearer token) and run systemctl restart vllm.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Pass a GPU through when creating the container. CPU-only inference is impractically slow.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The model downloads from HuggingFace on first start. Change it, HF_TOKEN (gated models) or extra flags (VLLM_SERVE_ARGS) in /opt/vllm/vllm.env, then run systemctl restart vllm.</div>
</div>
