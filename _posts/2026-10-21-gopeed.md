
## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The login password is generated during the install and stored in /opt/gopeed_data/config.json. Run systemctl restart gopeed after changing it.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Keep /opt/gopeed_data/config.json valid JSON. If Gopeed cannot parse it, it starts without any login on an empty database.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The REST API and the browser extension's remote mode use the apiToken from the same file, sent as the X-Api-Token header.</div>
</div>
