## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/cypht.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Sign in with the username and generated password stored as CYPHT_ADMIN_USER and CYPHT_ADMIN_PASS in /opt/cypht_data/.env.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Added mail accounts and settings are only kept after Save (or Save and Logout), encrypted with the login password. There is no password reset.</div>
</div>
