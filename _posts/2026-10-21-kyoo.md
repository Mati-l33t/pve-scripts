## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/kyoo.sh)"
```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>There is no default account: the first account registered becomes the administrator, so create it right after the install.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Kyoo uses HTTPS with a self-signed certificate, so accept the browser warning. Until the first video is scanned, the home page only shows "Resource not found.".</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Behind a reverse proxy or under another address, set PUBLIC_URL and JWT_ISSUER in /opt/kyoo_data/.env to the same new URL, then run systemctl restart kyoo-auth kyoo-api kyoo-scanner.</div>
</div>
