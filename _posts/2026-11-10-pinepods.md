## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/pinepods.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>There is no default account. The first visit to the web UI asks you to create the admin user.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>HOSTNAME and SERVER_URL in /opt/pinepods_data/.env must match the address you open PinePods at. Change them for a new IP or a reverse proxy, then run systemctl restart pinepods.</div>
</div>
