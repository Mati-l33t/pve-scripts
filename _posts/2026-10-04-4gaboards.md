
## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The admin password is DEFAULT_ADMIN_PASSWORD in /opt/4gaboards_data/.env. Log in as admin and change it under Settings.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Registration is open: anyone who reaches the port can create an account. Turn off User Registration in Settings &gt; Instance Settings if that is not wanted.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Realtime updates only work from the address in BASE_URL (/opt/4gaboards_data/.env). Behind a reverse proxy or domain, change it, add TRUST_PROXY=1 and run systemctl restart 4gaboards.</div>
</div>
