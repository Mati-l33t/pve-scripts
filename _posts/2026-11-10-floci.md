**Default install:**
```bash

```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Floci has no authentication. Use any non-empty AWS access key and secret (for example test/test), region us-east-1, and set the endpoint URL to http://&lt;container-ip&gt;:4566. Keep it on a trusted network.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Docker is not installed, so services that run containers (Lambda, ECS, RDS, ElastiCache, EKS and similar) are limited or unavailable. S3, SQS, SNS, DynamoDB and the other core services work.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Response URLs such as SQS queue URLs use FLOCI_BASE_URL in /opt/floci_data/.env, set to the container IP at install. Update it and restart floci when the IP changes or clients reach Floci through a hostname.</div>
</div>
