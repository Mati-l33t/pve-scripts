## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/vane.sh)"
```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Vane has no login: anyone who reaches port 3000 can read the chat history and the provider API keys. Keep it on a trusted network or behind an authenticating reverse proxy.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The first visit opens the setup screen: add an AI provider and pick a chat and an embedding model. Ollama on another host must listen on 0.0.0.0 and is entered as http://&lt;ollama-ip&gt;:11434.</div>
</div>
