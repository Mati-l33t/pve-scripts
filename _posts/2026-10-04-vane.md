It searches the web through SearXNG, reads the results and answers with cited sources, using a local LLM through Ollama or a cloud provider such as OpenAI, Anthropic, Gemini or Groq. It also offers speed, balanced and quality modes, academic and discussion search, image and video search, file uploads and a search history. This script builds Vane from source and runs a private SearXNG instance with JSON output next to it."


## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>No AI provider is configured. The first visit to port 3000 opens the setup screen: add Ollama, OpenAI, Anthropic, Gemini, Groq or any OpenAI-compatible server there and pick a chat and an embedding model. Ollama on another host must listen on 0.0.0.0 and be entered as http://<ollama-ip>:11434.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Vane has no login. Anyone who reaches port 3000 can use it, read the chat history and see the provider API keys in the settings, so keep it on a trusted network or behind an authenticating reverse proxy.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The bundled SearXNG only listens on 127.0.0.1:8888 and is configured in /etc/searxng/settings.yml (restart with systemctl restart searxng). To use your own instance instead, enable the json format there and change the SearXNG URL in Vane's settings.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Settings and API keys (config.json), the chat history (db.sqlite) and uploaded files live in /opt/vane_data, which updates leave untouched.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Install and every update build Vane from source, which takes about 10 minutes on 2 cores and needs the 4 GB of RAM and 12 GB of disk. Vane and SearXNG together idle at about 500 MB, so the RAM can be lowered after the install and raised again before an update.</div>
</div>
