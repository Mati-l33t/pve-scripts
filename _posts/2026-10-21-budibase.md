## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/budibase.sh)"
```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>There is no default account: create the admin on the setup page right after the install. Until then anyone who reaches port 80 can claim it.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Without a license key Budibase runs the free self-hosted plan: one workspace, unlimited users and rows, no user groups and no custom AI providers.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>AI agents and custom AI providers also need your own LiteLLM proxy: set LITELLM_URL and LITELLM_MASTER_KEY in /opt/budibase_data/.env and run systemctl restart budibase-server.</div>
</div>
