## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVED/main/ct/mailpit.sh)"
```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Mailpit captures email for testing; configure applications to use SMTP on port 1025. Do not expose the web UI or SMTP port to untrusted networks without adding authentication and TLS.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Captured messages are stored persistently in /opt/mailpit/data/mailpit.db and Mailpit keeps the newest 500 messages by default.</div>
</div>
