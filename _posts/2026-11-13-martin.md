## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/martin.sh)"
```
<div class="resource-bar">
  <span class="res-pill res-cpu">CPU: 1 cores</span>
  <span class="res-pill res-ram">RAM: 1024 MB</span>
  <span class="res-pill res-disk">Disk: 4 GB</span>
  <span class="res-pill res-os">OS: Debian 13</span>
</div>

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Copy .pmtiles or .mbtiles files into /opt/martin_data/tiles; Martin publishes them without a restart.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>For PostGIS, add a postgres connection_string to /opt/martin_data/config.yaml and restart Martin. It then publishes every spatial table and function that database user can read.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Martin has no authentication: the web UI and every source are open to anyone who can reach port 3000.</div>
</div>
