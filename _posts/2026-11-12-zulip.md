## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/zulip.sh)"
```

  <span class="res-pill res-cpu">CPU: 2 cores</span>

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Create your organization with the single-use link in ~/zulip.creds inside the container, then accept the self-signed certificate.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The hostname is fixed at install (default: the container IP). Give the container a static IP or set var_zulip_hostname to a DNS name.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Invitations and password resets need outgoing email; configure SMTP in /etc/zulip/settings.py.</div>
</div>
