## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVED/main/ct/lingarr.sh)"
```

Config file:
```
/opt/lingarr.env
```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Set a translation backend in /opt/lingarr.env before use. The default points at a LibreTranslate instance that does not exist yet - either deploy one and set LIBRE_TRANSLATE_URL, or switch SERVICE_TYPE to a hosted provider and add its API key.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Mount your media libraries into the LXC and connect Radarr/Sonarr through the web UI. Lingarr writes subtitle files next to the media, so it needs write access to those paths.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Needs the .NET 10 SDK, which Debian does not ship - it comes from the Microsoft repository. The build is therefore large; the compiled output lands in /opt/lingarr_app while the source tree stays in /opt/lingarr.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Metadata is stored in the local PostgreSQL database 'lingarr'. Upstream also supports MySQL and SQLite via DB_CONNECTION.</div>
</div>
