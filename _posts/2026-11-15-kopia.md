## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Open https://IP:51515 and accept the self-signed certificate. The UI and repository passwords are in /opt/kopia_data/.env; keep the repository password safe, without it the backups cannot be decrypted.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The default repository lives on the container disk in /opt/kopia_data/repository. For real backups connect a repository on a mount point, NAS or S3/B2 storage from the UI.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Remote Kopia clients need a user from <code>kopia server user add</code> and the certificate fingerprint of /etc/ssl/kopia/kopia.crt.</div>
</div>
