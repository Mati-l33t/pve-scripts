## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/engram.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Sign in to the dashboard with ENGRAM_CLOUD_ADMIN from /opt/engram_data/.env. Clients sync with ENGRAM_CLOUD_TOKEN: engram cloud config --server https://[IP], then engram cloud enroll &lt;project&gt;.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Clients only send their token over trusted HTTPS. Add /etc/ssl/engram/engram.crt to each client's trust store, or put Engram behind a reverse proxy with a valid certificate.</div>
</div>
