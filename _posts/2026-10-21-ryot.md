## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/ryot.sh)"
```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>There is no default login: the first account you register becomes the admin. Registration stays open, so set USERS_ALLOW_REGISTRATION=false in /opt/ryot_data/.env afterwards and restart ryot-backend.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Movies and shows need MOVIES_AND_SHOWS_TMDB_ACCESS_TOKEN, video games need the two VIDEO_GAMES_TWITCH_* keys. Add them to /opt/ryot_data/.env and restart ryot-backend.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Behind a reverse proxy or after an IP change, set FRONTEND_URL in /opt/ryot_data/.env to the new address and restart ryot-backend.</div>
</div>
