```bash

```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>There is no default account and only one admin is allowed. Create it in the Admin Console on port 3002 right after the install, before anyone else does.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Both ports use a self-signed certificate. Accept it on https://[IP]:3001 as well as on port 3002, or the Admin Console cannot reach the API.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>For real OIDC use, put Logto behind a reverse proxy: set ENDPOINT and ADMIN_ENDPOINT in /opt/logto_data/.env to your HTTPS domains, add TRUST_PROXY_HEADER=1, drop the HTTPS_* lines and restart logto.</div>
</div>
