## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/new-api.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Sign in with the admin user and password stored in /opt/new-api_data/.env.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Self-registration is open by default. Turn it off under System Settings &gt; Basic Authentication if others can reach the instance.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Behind an HTTPS reverse proxy, set SESSION_COOKIE_SECURE=true and SESSION_COOKIE_TRUSTED_URL to the public origin in /opt/new-api_data/.env, then restart new-api.</div>
</div>
