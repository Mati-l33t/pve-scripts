## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/pve-ups.sh)"
```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Set a password and configure your Proxmox API token (requires Sys.PowerMgmt privilege) through the first-access setup wizard at http://CT-IP:8080.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Requires a UPS with an SNMP network card (RFC 1628 or a vendor MIB such as APC PowerNet) or a reachable NUT server on TCP port 3493.</div>
</div>
