## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/fizzy.sh)"
```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The first email address that signs up becomes the account owner and sign-up closes after that, so open Fizzy right after the install.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Without SMTP, read the sign-in code with: sqlite3 /opt/fizzy_data/production.sqlite3 "select code from magic_links order by created_at desc limit 1"</div>
