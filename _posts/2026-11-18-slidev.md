## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/slidev.sh)"
```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Slidev has no authentication: anyone who can reach port 3030 can present, edit the slides and use the MCP endpoint. Keep it on a trusted network.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The deck lives in /opt/slidev/slides.md. AI agents can edit it over MCP at http://[IP]:3030/__mcp.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>To reach it through a hostname or reverse proxy, add that host to server.allowedHosts in /opt/slidev/vite.config.ts.</div>
</div>
