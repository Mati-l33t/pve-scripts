## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVED/main/ct/stash.sh)"
```
<div class="resource-bar">
  <span class="res-pill res-cpu">CPU: 2 cores</span>
  <span class="res-pill res-ram">RAM: 2048 MB</span>
  <span class="res-pill res-disk">Disk: 8 GB</span>
  <span class="res-pill res-os">OS: Debian 13</span>
</div>

## Configuration

Config file:
```
/opt/stash_data/config.yml
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>On first start Stash runs a setup wizard at http://[IP]:9999 where you pick your media directories and optionally set a username and password.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Configuration, database and generated content live in /opt/stash_data, outside the app directory, so they survive updates. Include this directory in your backups.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Media files are not stored in the container. Mount your library into the LXC (for example via a Proxmox bind mount) and point the Stash scan directories at the mount path.</div>
</div>
