```bash

```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Connect your RivetKit app with RIVET_ENDPOINT=http://default:&lt;token&gt;@[IP]:6420, using auth.admin_token from /opt/rivet_data/config.json. The default node pool already exists.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Port 6420 is the API and actor gateway, not a web UI; the self-hosted engine ships no dashboard.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The admin token has full access to every namespace. Keep it on your backend and put the engine behind HTTPS before exposing it beyond your LAN.</div>
</div>
