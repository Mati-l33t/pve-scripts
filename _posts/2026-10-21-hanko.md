## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Hanko is an API, not a web app: port 8000 only shows a status page and there is no admin UI. Your own app's login talks to it through Hanko Elements or the SDKs.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Passkeys need HTTPS on a domain name. Publish port 8000 through a TLS reverse proxy, put that domain and your SMTP server in /opt/hanko_data/config.yaml and run systemctl restart hanko.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The admin API on 127.0.0.1:8001 has no authentication. Anyone who reaches it can sign in as any user, so never expose it without a firewall or an authenticating proxy.</div>
</div>
