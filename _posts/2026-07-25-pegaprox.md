## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/pegaprox.sh)"
```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>PegaProx is pre-1.0 BETA software with frequent, sometimes breaking releases. This script lives in the experimental ProxmoxVED repo - snapshot/back up before updating.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The web UI is served over HTTPS on port 5000 with a self-signed certificate on first boot - accept the browser certificate warning. The first login creates the admin account.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>PegaProx connects to Proxmox clusters remotely via the Proxmox API and SSH - add your cluster credentials in the web UI after first login. It does not need to run on a PVE node.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Besides port 5000 (web), PegaProx also uses port 5001 (VNC WebSocket) and port 5002 (SSH WebSocket) for the in-browser consoles.</div>
</div>
