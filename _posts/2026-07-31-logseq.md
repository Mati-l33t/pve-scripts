## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Open the app at https://[IP] and accept the self-signed certificate. HTTPS is required: Logseq's local database uses OPFS (navigator.storage.getDirectory) and SharedArrayBuffer, which browsers only expose in a secure, cross-origin-isolated context — over plain HTTP the graph fails to load. nginx serves it over TLS with the COOP/COEP isolation headers set.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>All graphs are stored locally in the browser (IndexedDB/OPFS). Clearing browser data removes your notes, so export and back up regularly.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>This is the self-hosted web build. Logseq does not ship a sync server (Logseq Sync is a separate paid hosted service), so graphs do not sync across devices or browsers.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The initial build compiles ClojureScript and can take 10+ minutes; generous RAM is required.</div>
</div>
