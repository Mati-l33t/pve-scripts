## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/unsloth.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Log in as unsloth with the password from ~/unsloth.creds in the container. To change it, run unsloth studio reset-password, which prints a new one.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Fine-tuning needs an NVIDIA GPU passed through to the container; without one, inference and export still work. After adding or changing a GPU, run the update to get matching builds.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Models are stored in /opt/unsloth_data and fill the disk fast (a 7B model at Q4 is about 4 GB). Add disk space if you plan to keep several.</div>
</div>
