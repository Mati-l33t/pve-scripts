## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/cap.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Sign in with any email address. Without Resend the login code is printed to the log: <code>journalctl -u cap-web -n 30</code>.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Login only works over HTTPS, so accept the self-signed certificate. The desktop app needs a trusted certificate: put Cap behind your own domain and set var_cap_url (or WEB_URL, NEXTAUTH_URL and S3_PUBLIC_ENDPOINT in the .env).</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Anyone who reaches Cap can create an account; restrict sign-ups with CAP_ALLOWED_SIGNUP_DOMAINS in /opt/cap_data/.env.</div>
</div>
