Drop in a video, pick a target size such as 8, 25 or 50 MB, and it calculates the bitrate and encodes to H.264, HEVC or AV1, with NVIDIA NVENC, Intel Quick Sync, VAAPI or CPU encoders, live progress, trimming, batch uploads, presets and a watched folder. This script builds the FastAPI backend, Celery worker and SvelteKit UI from source and runs them with Redis and FFmpeg."

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The UI and API are protected by HTTP Basic auth. The user is admin, the generated password is AUTH_PASS in /opt/8mblocal_data/.env. It can be changed or switched off under Settings, Authentication.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Uploads and compressed results are deleted after 1 hour, checked every 15 minutes. Download results right away, or raise the retention under Settings. Both live in /opt/8mblocal_data, so give the disk room for the largest video you compress.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Hardware encoding needs GPU passthrough. Intel Quick Sync, Intel and AMD VAAPI and NVIDIA NVENC are probed when the worker starts and only offered when a test encode passes; the CPU encoders x264, x265 and SVT-AV1 always work. For NVENC the NVIDIA libraries in the container must match the host driver version.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Uploads are written to disk (MEDIA_STORAGE=disk in /opt/8mblocal_data/.env). Upstream defaults to auto, which stages uploads in /dev/shm and counts them against the container RAM.</div>
</div>
