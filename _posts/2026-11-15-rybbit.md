## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/rybbit.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Open https://[IP]/signup and accept the self-signed certificate; the first account becomes the admin. Then set DISABLE_SIGNUP=true in /opt/rybbit_data/.env and restart rybbit-server.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Visitors' browsers only load the tracking script from a trusted HTTPS address. Put Rybbit behind a reverse proxy with a real certificate and pass that URL as var_base_url at install; it is compiled into the web client.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>ClickHouse needs a CPU with AVX2 on x86.</div>
</div>
