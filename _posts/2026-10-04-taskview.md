## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The default login user / user1!#Q is publicly documented. Sign in right after the install and claim the account under Account settings > Login and email (set your own login, email and password).</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Without SMTP only the default account can sign in: sign-up, invitations and magic-link login all confirm the email address by mail. For more users add the SMTP_* settings from https://taskview.tech/docs/configuration/environment-variables to /opt/taskview_data/.env, consider ALLOW_PUBLIC_REGISTRATION=false (invited emails only), then run systemctl restart taskview.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The API only accepts browser requests from the origins in CORS_ALLOWED_ORIGINS, and builds email and OAuth links from APP_URL, both set to the container IP in /opt/taskview_data/.env. Change them when the IP changes or TaskView is reached through a hostname or reverse proxy (CORS_ALLOWED_ORIGINS takes a comma-separated list), then run systemctl restart taskview.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>TaskView is source-available, not open source: the TaskView Source-Available License allows personal, family and internal company use, but forbids offering it to third parties as a hosted service or building a competing product on it.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Install and every update build TaskView from source, which needs about 4 GB of RAM (the API bundle is minified with Terser). The running services use far less, so the RAM can be lowered after the install and raised again before an update.</div>
</div>
