## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVED/main/ct/nextdns.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>During install you will be asked for your NextDNS profile ID (or pass var_nextdns_profile). The script runs: nextdns install -profile <id> -report-client-info -setup-router</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Create or copy your profile ID from https://my.nextdns.io before running the script.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>After install, NextDNS listens on TCP/UDP port 53. Point DHCP clients at the container IP:53, or set the container as upstream DNS on your router. There is no local web UI (profiles are managed at my.nextdns.io).</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Router mode (-setup-router) makes this LXC the DNS server for your network.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Updates use the official NextDNS apt repository (repo.nextdns.io). Run the container update script or apt upgrade inside the LXC.</div>
</div>
