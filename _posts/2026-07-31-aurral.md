## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVED/main/ct/aurral.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>On first access at http://IP:3001, create the admin account and connect your Lidarr instance.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Application data (SQLite database aurral.db) is stored in /opt/aurral/data. Include it in regular container backups.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Aurral compiles native modules and builds the frontend during installation; allow several minutes for setup.</div>
</div>
