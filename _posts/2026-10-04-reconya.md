## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Log in as admin with the generated LOGIN_PASSWORD from /opt/reconya_data/.env. To change it, edit that file and run systemctl restart reconya.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Sessions are signed with a key built into the binary, so a session cookie from any Reconya install works on yours. Keep port 3008 on a trusted network, never on the internet.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Nothing is scanned until you add a network under Networks and start a scan. ARP and MAC discovery only reach the bridges or VLANs the container has an interface on.</div>
</div>
