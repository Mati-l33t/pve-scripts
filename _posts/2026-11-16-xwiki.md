## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/DevScripts/main/ct/xwiki.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>On first start open http://[IP]:8080/xwiki/ and finish the Distribution Wizard: create the admin account and install the XWiki Standard flavor. This takes a few minutes.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The PostgreSQL database and its random password are created by the Debian package; the connection is stored in /etc/xwiki/hibernate.cfg.xml.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The Java heap is set to about 60 % of the container RAM in /etc/default/tomcat10. XWiki needs at least 2 GiB, 4 GiB is recommended.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Take a snapshot or backup before updating; major XWiki upgrades finish with the Distribution Wizard in the browser.</div>
</div>
