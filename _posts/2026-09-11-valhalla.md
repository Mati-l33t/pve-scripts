description: "Valhalla is an open-source routing engine and accompanying libraries for use with OpenStreetMap data. It provides turn-by-turn routing, map matching (snapping noisy GPS traces to the road/path network), time+distance matrices, isochrones and elevation lookups over a self-built tile graph. Commonly run as a self-hosted routing backend so that location data never has to be sent to a third party."

## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVED/main/ct/valhalla.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Installed by compiling from source (no prebuilt package exists), which takes roughly 20-45+ minutes depending on CPU/RAM.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>No routing tiles are built during install. Find your region's extract at https://download.geofabrik.de/ (browse to a continent, then country/region, and copy the .osm.pbf download link), then build the graph with: /opt/valhalla_data/build-tiles.sh <pbf-url>. Avoid planet-wide data unless the container is sized for it.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The HTTP API on port 8002 has no authentication - keep it on a private/internal network.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>To use this as the map-matching backend for GeoPulse, set GEOPULSE_TIMELINE_MAP_MATCHING_ENABLED=true, GEOPULSE_TIMELINE_MAP_MATCHING_PROVIDER=valhalla and GEOPULSE_TIMELINE_MAP_MATCHING_VALHALLA_BASE_URL=http://<this-container-IP>:8002 on the GeoPulse backend.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The default 24GB disk / 8192MB RAM only covers the build. Routing tiles need several times the compressed extract size in free disk, so resize the container before building tiles for large regions.</div>
</div>
