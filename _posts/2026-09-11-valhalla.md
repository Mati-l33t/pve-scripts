description: "Valhalla is an open-source routing engine and accompanying libraries for use with OpenStreetMap data. It provides turn-by-turn routing, map matching (snapping noisy GPS traces to the road/path network), time+distance matrices, isochrones and elevation lookups over a self-built tile graph. Commonly run as a self-hosted backend for apps like GeoPulse that need map matching without sending location data to a third party."

## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVED/main/ct/valhalla.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Compiled from source on first install - there is no official Debian/Ubuntu package. Expect the install to take 20-45+ minutes depending on CPU/RAM.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>No routing tiles are built during install, since that requires an OSM extract for the region you actually travel in. Run /opt/valhalla_data/build-tiles.sh <geofabrik-pbf-url> afterwards, e.g. with a https://download.geofabrik.de extract for your country. Avoid planet-wide data unless the container is sized for it.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The HTTP API (used for /status, /trace_route, /trace_attributes, etc.) listens on port 8002 with no authentication - keep it on a private/internal network.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>To use this as the map-matching backend for GeoPulse, set GEOPULSE_TIMELINE_MAP_MATCHING_ENABLED=true, GEOPULSE_TIMELINE_MAP_MATCHING_PROVIDER=valhalla and GEOPULSE_TIMELINE_MAP_MATCHING_VALHALLA_BASE_URL=http://<this-container-IP>:8002 on the GeoPulse backend.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Updating rebuilds Valhalla from source at the latest GitHub release tag; existing tiles/config in /opt/valhalla_data are left untouched.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The default 24GB disk / 8192MB RAM only covers the build. A country-sized Geofabrik extract needs roughly 4-8x its compressed size in free disk for tiles, and building/updating wants more RAM than steady-state serving - resize the container before running build-tiles.sh or before updating if you shrank it after the initial install.</div>
</div>
