## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/dreeve.sh)"
```
<div class="resource-bar">
  <span class="res-pill res-cpu">CPU: 2 cores</span>

  <span class="res-pill res-disk">Disk: 10 GB</span>
  <span class="res-pill res-os">OS: Debian 13</span>
</div>

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Create a Strava API application at https://www.strava.com/settings/api, put STRAVA_CLIENT_ID, STRAVA_CLIENT_SECRET and STRAVA_REFRESH_TOKEN into /opt/dreeve/.env.local and run systemctl restart dreeve.</div>
</div>

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>Upstream only supports Docker. This script runs the same FrankenPHP setup natively, so an upstream change can break it.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>FIT file import and push notifications are unavailable: the fit-tool and shoutrrr binaries of the official image are not included.</div>
</div>
