## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>The admin login and the Default project's API keys are saved to ~/langfuse.creds inside the container. Sign-up is off, invited users included; set AUTH_DISABLE_SIGNUP=false in /opt/langfuse_data/.env and restart langfuse-web while adding users.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Behind a reverse proxy, set NEXTAUTH_URL in /opt/langfuse_data/.env to the external URL and restart langfuse-web.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Media uploads and batch exports are not configured; they need an S3 endpoint reachable by clients.</div>
</div>
