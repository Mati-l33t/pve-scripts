## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVED/main/ct/shlink.sh)"
```

## Notes

<div class="warn-callout">
  <i class="fas fa-exclamation-triangle"></i>
  <div>The initial API key is stored in /opt/shlink/.env. You need it to connect Shlink Web Client or any API consumer.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Configure your short domain by editing DEFAULT_DOMAIN in /opt/shlink/.env and restarting the service.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Shlink API runs on port 8080, the Web Client (if installed) on port 3000.</div>
</div>
