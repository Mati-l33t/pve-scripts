```bash

```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Registration is closed. Create an account inside the container with <code>ATUIN_CONFIG_DIR=/opt/atuin_data atuin-server admin user create --email you@example.com you</code>, or set <code>open_registration = true</code> in the config to let clients run <code>atuin register</code>.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>Set <code>sync_address = "http://[IP]:8888"</code> in each client's ~/.config/atuin/config.toml, then <code>atuin login</code> and <code>atuin sync</code>. Put a TLS reverse proxy in front before exposing it beyond your LAN.</div>
</div>
