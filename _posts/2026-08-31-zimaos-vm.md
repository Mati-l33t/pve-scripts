## Installation

**Default install:**
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVED/main/vm/zimaos-vm.sh)"
```

## Notes

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>This VM boots an installer image. Open the console after creation and complete the installation there, selecting scsi0 as the target disk.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>ZimaOS does not print its IP address on the console. Read it from the Proxmox summary once the guest agent is running.</div>
</div>

<div class="info-callout">
  <i class="fas fa-info-circle"></i>
  <div>For a real NAS, add a second disk in Proxmox and let ZimaOS manage it. Keeping data off the system disk survives reinstalls.</div>
</div>
